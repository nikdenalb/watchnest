# Local Rules

Personal Cursor rules for this machine/developer. Not part of the shared
project conventions.

- Files under this directory are gitignored, except this README.
- Shared project rules live in `.cursor/rules/` (without the `local/` folder).
- Add personal always-on or module-scoped rules here using the `*.local.mdc`
  suffix (or place them directly in this folder).

This README only marks the location. Do not put personal workflow, agent roles,
or private process notes here — keep those in ignored `*.local.mdc` files (or
other ignored docs such as under `secrets/`).
